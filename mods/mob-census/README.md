# Mob Census

Displays real-time counts of nearby hostile and passive mobs on your HUD.

## Features

- **Entity Counts**: Lists nearby **Hostile** and **Passive** mobs with individual counts (in descending order) and category totals.
- **Named Mobs**: Name-tagged mobs are listed separately by their custom name.
- **Keybinds**:
  - Toggle Hostile: `Alt + H`
  - Toggle Passive: `Alt + N`
- **Configurable**: In-game settings for detection radius, scan rate, appearance, and keybinds via Cloth Config.

## Requirements

- **Fabric**: Fabric API, [Cloth Config](https://modrinth.com/mod/cloth-config), [Mod Menu](https://modrinth.com/mod/modmenu) (recommended for in-game config)
- **NeoForge**: [Cloth Config](https://modrinth.com/mod/cloth-config)

## Note

- This is a **client-side only** mod.
